How an agent works

The agent loop, from task to outcome.

Perceive, understand, plan, remember, call tools, act and evaluate. Pick a stage or press play to follow a sample task around the loop.

Autonomy is configured, not assumed

Each agent operates with defined permissions, human approval points and safety controls. The level of autonomy is set per workflow and widened only as evidence supports it.

Multi-agent systems

One intelligent ecosystem. Multiple specialised agents.

This is a live mission-control board. Drag any node, select one to read its role, then dispatch a request to watch it travel from orchestrator to result.

Agent coordination

An orchestrator sequences work, tracks state and decides when a task is complete.

Task delegation

Sub-tasks are routed to the agent with the right instructions and tools.

Shared context

Agents read from and write to a common, access-controlled context.

Memory management

Short-term working memory and long-term knowledge are kept separate and governed.

Tool integration

Agents reach systems through approved tools with scoped permissions.

Human-in-the-loop approvals

Defined actions pause for a person to approve, edit or reject.

Execution monitoring

Every step is traced so behaviour can be inspected, evaluated and audited.
