Capability layers

The stack, layer by layer.

AI Models

  • OpenAI
  • Anthropic
  • Google Gemini
  • Open-source LLMs

Model choice is made per use case, weighing capability, latency, cost, data-residency needs and licensing. Architectures can be designed so models are swappable.

Agent Frameworks

  • LangGraph
  • CrewAI
  • AutoGen
  • Semantic Kernel

Frameworks provide the orchestration, state and control-flow building blocks for agents. We choose the one that fits the workflow, or build lightweight custom orchestration when that is simpler.

Agent Protocols

  • MCP
  • A2A

Open protocols standardise how agents reach tools and data (MCP) and how agents communicate with one another (A2A), reducing bespoke glue code.

RAG & Knowledge

  • Vector databases
  • Embeddings
  • Hybrid search
  • Document processing

Retrieval-augmented generation grounds agents in your own content. Ingestion, chunking, hybrid retrieval and access control are engineered as a system, not an afterthought.

Backend

  • Python
  • FastAPI
  • Node.js

Service layers expose agents and tools through well-defined APIs with authentication, validation and logging.

Database

  • PostgreSQL
  • MongoDB
  • Redis

Operational data, agent state, conversation history and caching are stored in the databases that suit each access pattern.

Frontend

  • React
  • Next.js
  • TypeScript

User interfaces for approvals, review, monitoring and end-user interaction with agents.

Automation

  • n8n
  • API integrations
  • Event-driven workflows

Triggers, schedules and event streams start agent workflows and connect them to the rest of your stack.

Infrastructure

  • Docker
  • Kubernetes
  • Cloud and private deployments

Containerised deployment on your cloud or in a private environment, with environment separation and secrets management.

AI Operations

  • Tracing
  • Evaluation
  • Observability
  • Monitoring
  • Guardrails

Production agents need tracing of every step, automated and human evaluation, monitoring and guardrails so behaviour can be inspected and improved.

How we choose

Fit over fashion.

The right model, framework and infrastructure depend on the task, the data, the risk profile and your team. We evaluate options against your requirements, keep architectures modular so components can be replaced, and prefer simple designs that can be tested and operated.

Every production system includes tracing, evaluation and guardrails, so behaviour can be inspected, measured and improved over time.
